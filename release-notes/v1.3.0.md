# Aura Store 1.3.0

Each server tab now looks like the site it reads, and the lists move without a stagger.

- Browse still carries one tab per catalogue. Every tab except the catalogue's own now opens on that
  site's front page, in the site's order: 5play's *Recommended*, *New games*, *Popular games*,
  *New apps* and *Popular apps*; GetModsAPK's *Featured*, *Updated Games* and *New Games*; AN1's
  *Latest games*; ApkVision's five game rows and three app rows; 9MOD's newest posts.
- A source's own name is a chip at the start of its category strip. Tapping it returns to that
  front page without reaching for the back gesture.
- The cards carry the numbers each site prints: the version, the size, the mod note, the developer
  or the rating. A site whose cards carry no version is not given one.
- Categories carry their counts where the source publishes them, as the 9MOD terms do.
- Tapping a category opens the site's two-column card grid, page by page, rather than a single rail.

## The scroll

The navigation bar asked for a copy of the whole page on every frame even when Blur was zero, then
paid for a render effect over the bar. That copy is what made every list drag while it moved. Only
Blur asks for a copy now. At zero the bar is the drawn material, with its tint, sheen, lens band and
colour rims, and the page underneath is never recorded or sampled.

The enable switch was also being read as the bar's shape, so the wrong bar could demand a copy.
That is fixed.

## The version

The version is 1.3.0 and the version code is 10300. The application id and the signing key are
unchanged, so this release updates an installed copy in place and keeps its data.

## Two builds

- `Aura-Store-v1.3.0.apk` is the build to install. It is signed with the project key, updates an
  installed copy in place, and is 2.49 MB.
- `Aura-Store-v1.3.0-debug.apk` is the debug build: 15.37 MB, debug-signed, with the full symbol
  set and no shrinking. It cannot replace or update a release install, and Android will refuse it
  over one. It is here for testing a change against a build that keeps every name.

Each file has a `.sha256` beside it. Compare with `sha256sum`, or with `Get-FileHash` on Windows.
