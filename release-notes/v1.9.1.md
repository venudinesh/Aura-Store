# Aura Store 1.9.1

The 1.9.0 release under a new version.

## What changed

Nothing but the version. `1.9.1 (10901)` is the 1.9.0 tree: every APKPorts file has a working link,
and the in-app update card installs over the old build instead of saving the APK.

## The version

The version is 1.9.1 and the version code is 10901. The application id and the signing key are
unchanged, so a 1.9.0 install updates in place.

## Two builds

- `Aura-Store-v1.9.1.apk` is the signed release build.
- `Aura-Store-v1.9.1-debug.apk` is the debug build: debug-signed, unshrunk, and not installable over
  a release copy.

Each file has a `.sha256` beside it. Compare with `sha256sum`, or with `Get-FileHash` on Windows.
