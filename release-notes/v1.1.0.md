# Aura Store 1.1.0

Every catalogue in the shop.

- The Browse tab carries a block for each catalogue you have switched on: the apps it published last,
  and the categories it groups them under. A catalogue's name opens that catalogue's own page.
- A download asks where it comes from first. The sheet lists every catalogue, says which of them
  has the app and which do not, and downloads from the one you pick.
- Settings has a default download source. The sheet opens there, already expanded.
- One search asks the catalogue and the other sites at the same time. Each site that answers gets a
  tab with the number of matches it returned, and one site's rows are on screen at a time. A row
  from another site downloads from that site, without asking again.
- 9MOD rows carry the app's icon, and their files download from the site's direct links.

Also in this release:

- A download link with a space in its path works. The signed token used to be added to the raw link
  and encoded afterwards, so the link that was signed and the link that was asked for were two
  different strings.
- A storage host whose name no longer resolves falls back to the sibling that serves the same path.
- UpdateMe is gone. The six catalogues are LiteAPKs, 9MOD, 5play, GetModsAPK, AN1 and ApkVision.

The application id and the signing key have not changed, so this release updates an installed copy in
place and keeps its data.

## Two builds

- `Aura-Store-v1.1.0.apk` is the build to install. It is signed with the project key, updates an
  installed copy in place, and is 2.46 MB.
- `Aura-Store-v1.1.0-debug.apk` is the debug build: 15.66 MB, debug-signed, with the full symbol set
  and no shrinking. It cannot replace or update a release install, and Android will refuse it over
  one. It is here for testing a change against a build that keeps every name.

Each file has a `.sha256` beside it. Compare with `sha256sum`, or with `Get-FileHash` on Windows.
