# Aura Store 1.9.2

The home's newest list now comes from every source, and 5play pages list their files again.

## New from every server

The Games home used to end on the catalogue's own newest posts, so the first screen read as one
site's feed. The default *Last Update* view now draws one row from every source you have on, taken a
round at a time: LiteAPKs, 9MOD, 5play, GetModsAPK, AN1, ApkVision and APKPorts all reach the first
screen before any one of them gets a second row.

Each row carries its source label. A catalogue row opens its own post; every other row opens the
source's page. The ranking chips still draw the catalogue's lists, and when every source refuses the
catalogue rows remain.

## 5play files

5play rebuilt its download box around `nx-file` rows linking `/en/download/<id>-<slug>.html`, and
the reader still expected the older `?do=cdn&id=` links. Every 5play app opened on *This page has no
downloadable file*. Both shapes are read now, and the signed R2 address behind the row is resolved
before the file is offered.

## The version

The version is 1.9.2 and the version code is 10902. The application id and the signing key are
unchanged, so a 1.9.x install updates in place.

## Two builds

- `Aura-Store-v1.9.2.apk` is the signed release build.
- `Aura-Store-v1.9.2-debug.apk` is the debug build: debug-signed, unshrunk, and not installable over
  a release copy.

Each file has a `.sha256` beside it. Compare with `sha256sum`, or with `Get-FileHash` on Windows.
